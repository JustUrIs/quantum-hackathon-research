# Tres enlaces para compartir

Entrada: https://justuris.github.io/quantum-hackathon-research/

Estas demos funcionan sin cuenta ni instalación. Son vistas previas: usan cálculos analíticos en JavaScript y referencias precalculadas con Qiskit. No ejecutan Python ni mandan trabajos a IonQ. El aviso aparece en cada página y en las exportaciones; el botón de backend está deshabilitado.

## LOST SIGNAL

https://justuris.github.io/quantum-hackathon-research/lost-signal/

**Gancho:** ¿Cuánto ruido hace falta para perder una mejora cuántica?

Recorrido de 45 segundos: observar la ganancia con cuatro sensores, subir el ruido hasta que el sensor independiente gane y comparar el modelo molecular con y sin anisotropía. El mapa es ilustrativo; no demuestra navegación.

## Q-DAY CLOCK

https://justuris.github.io/quantum-hackathon-research/qday-clock/

**Gancho:** Dos histogramas iguales. Solo uno calculó el orden sin recibir la respuesta.

Recorrido de 45 segundos: comparar el circuito genuino y la imitación, mirar el coste en compuertas y cambiar a N=33, base 2 para ver un fracaso válido. Cambiar a base 5 y recuperar factores. El reloj es un escenario de planificación, no una predicción del fin de RSA.

## ORDER

https://justuris.github.io/quantum-hackathon-research/order/

**Gancho:** Cambiá el orden de las preguntas. ¿Cambió también tu conclusión?

Recorrido de 45 segundos: intercambiar AB y BA, insertar una rotación para romper QQ y abrir el modelo clásico que reproduce las probabilidades. Terminar con el auditor de conteos: sirve para estudiar instrumentos de medición con grupos independientes asignados al azar. No prueba que el cerebro sea cuántico.

## Uso comercial

Usar un solo enlace según la audiencia. Para educación y divulgación, Q-DAY permite explicar cómo auditar una demostración. Para equipos de investigación de usuarios, ORDER abre una conversación sobre efectos del cuestionario. Para docencia de física, LOST SIGNAL hace visible el coste del ruido.

Los mensajes y pilotos de `01` a `04` son borradores preparados para el equipo. No se enviaron contactos, correos ni publicaciones en redes. La publicación de estas vistas previas tampoco constituye una entrega en Qollab.
