# DARKROOM web companion

Static, dependency-free analytical explainer for Vercel. A six-step English/Spanish lesson explains single photons, path mixing, interference, absorbing objects and final detectors, with a four-question comprehension check. Sliders recalculate exact probability accounting in JavaScript. This companion does not run Qiskit or a quantum backend. The hackathon's circuit, local BasicSimulator measurement and optional selected-backend experiment are in `darkroom-qollab/`.

Deploy this directory as the Vercel project root. Replace the generic Qollab homepage link with the published project URL after the Qollab project is public.
