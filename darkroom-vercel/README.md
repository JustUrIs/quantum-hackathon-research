# DARKROOM web companion

Static, dependency-free analytical explainer for Vercel. Sliders recalculate exact probability accounting in JavaScript. This companion does not run Qiskit, simulate a quantum backend, or claim it does. The hackathon's circuit and backend experiment are in `darkroom-qollab/`.

Deploy this directory as the Vercel project root. Replace the generic Qollab homepage link with the published project URL after the Qollab project is public.
