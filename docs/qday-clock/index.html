Give the classical side a fair hearing.

Success per attempt, not runtime advantage. Random-phase baseline: 6 uniform bits through identical post-processing. Random-GCD baseline: a uniform integer from 2 to N−1. Trial division is deterministic and wins easily at these sizes.

Exactly what this experiment can establish

This is a genuine small-N order-finding circuit, built from a reversible multiplication truth table. Truth-table synthesis grows exponentially and is not scalable Shor arithmetic. Gate counts describe this implementation in an RX/RY/RZ/CX basis, not an optimized resource estimate for RSA. The pre-solved imitation proves that an output histogram alone does not certify the algorithm. Local execution is a classical statevector simulation.

Continued-fraction convergents must pass a modular check before we extract a nontrivial factor. We do not search all possible periods inside the recovery path. Some measured phases fail; those failures count.
